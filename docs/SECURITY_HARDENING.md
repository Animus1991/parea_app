## 2. Νέες ρυθμίσεις περιβάλλοντος

| Μεταβλητή | Τι κάνει |
|---|---|
| `ALLOWED_ORIGINS` | Ακριβή ξένα origins που επιτρέπονται, χωρισμένα με κόμμα |
| `EVENTS_WRITE_TOKEN` | 16+ χαρακτήρες. Απαιτεί `Authorization: Bearer <token>` για εγγραφές εκδηλώσεων |
| `EVENTS_WRITE_MODE` | `open` ανοίγει τις εγγραφές σε όλους. Μόνο για προσωρινές επιδείξεις |
| `EVENTS_WRITE_LIMIT_PER_MINUTE` | Όριο εγγραφών ανά IP, προεπιλογή 20 |
| `GEMINI_TEXT_MODEL` | Μοντέλο για σύντομα κείμενα. Προεπιλογή ίδιο με `GEMINI_MODEL` |
| `TRUST_PROXY` | Όταν ο server είναι πίσω από CDN ή proxy, για σωστή IP στα όρια ρυθμού |

## 4. Τι μένει ανοιχτό

Αυτά χρειάζονται πραγματικό backend ταυτότητας:
- Επαληθευμένοι ρόλοι στον server (custom claims). Σήμερα οι φρουροί του client είναι μόνο UX.
- Η ταυτότητα στο Socket.IO δηλώνεται από τον client κατά τη σύνδεση. Χρειάζεται επαλήθευση token.
- Τα `memberIds` των δωματίων chat πρέπει να τα γράφει Cloud Function.
- Η σύνδεση επίδειξης (demo login) υπάρχει ακόμη στο UI.
- `npm audit`: αναβαθμίσεις εξαρτήσεων που σπάνε συμβατότητα.
- CSP header: χρειάζεται καταγραφή όλων των εξωτερικών πηγών (χάρτες, εικόνες, Firebase) πριν ενεργοποιηθεί.
