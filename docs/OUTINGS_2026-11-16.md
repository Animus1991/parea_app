# Group outings (Φ27) — the competitive-analysis plan, built — 2026-11-16

What this round adds: all 20 ideas of the competitive analysis (Timeleft, Meetup, Bumble BFF,
Partiful, Luma, DICE, Fever, Pie, Loft, more.com, komoot, IRL lessons), the two «aesthetic»
items («Η βραδιά μας» and the «Η παρέα σου είναι έτοιμη» moment), and the backend pieces that
can be built without a live Firebase project. No existing feature was removed; the ones touched
were upgraded (listed in §4).

**Aesthetic items.** «Η βραδιά μας» (`/night/:groupId`) gathers the night in one screen:
the moment header (cover gradient, members, status «Η παρέα σου είναι έτοιμη»), door ticket /
check-in, meeting point, pre-meet, group code, who is coming + composition, route, invites,
tickets, waitlist, safety, leaving. The first time a confirmed group is opened the header
animates and explains what is below; joining the last seat also sends the notification
«Η παρέα σου είναι έτοιμη!». Plans and event group cards link to it.

## 2. Rules that protect people (enforced in the store, mirrored in rules / backend)

* Only the host (or, with no host, a member) checks people in, only members, only while open
  (2 h before → 6 h after start; always open in demo mode, with a note).
* Absences count only if **≥ 2** people were confirmed at the door — one person cannot mark a
  whole group absent.
* Leaving a confirmed group < 24 h before counts as a late cancel **only if the seat stays empty**.
* One join gate for every way in (`canJoinGroup`): capacity → waitlist, women & non-binary,
  blocks either way, paused/under-review standing for groups with strangers.
* Copilot «leave group» no longer offers an undo that cannot work after a seat hand-over.

## 4. Existing features upgraded (nothing removed)

* `joinGroup` now goes through the join gate; `createGroup(eventId, size, { genderMode })`.
* `leaveGroup`: seat hand-over, late-cancel strike only when the seat stays empty, commitment
  hold released, plain notifications.
* Plans «Αποχώρηση»: **bug fixed** — it left the first group of the event, not necessarily
  yours; it also says what leaving means before you confirm.
* Pending feedback opens as soon as the host closes check-in.
* `verifyDemo` records method + date (`verifiedVia`), never the document.
* Event card match % and Plans «Αποχώρηση» button: AA contrast fixes found by the new checks.
* «Λεπτομέρειες Περιπέτειας»: semantic tokens (readable in every theme) + real route difficulty.
